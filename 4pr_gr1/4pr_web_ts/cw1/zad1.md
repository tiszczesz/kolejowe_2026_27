1. Wygeneruj projekt używający npm
2. Zainstaluj typescript lokalnie
```console
npm i typescript -save-dev
npm i typescript -D
```
3. Wygeneruj tsconfig.json
4. src dist  npx tsc -w
5. plik index.ts w src
6. Plik data.ts zawierający dane contacts string[]
7. Zaimportuj do index.ts
8. Wyświetl w pętli
```ts 
console.log(`Kontakt nr. 1..max ${contact}`)
```
